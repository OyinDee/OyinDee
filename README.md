---

I build backends that handle money, messages and real users. Most of my work is
Node.js and TypeScript — payment flows, wallets, order systems, real-time
messaging — with a parallel .NET practice in ASP.NET Core and Azure SQL.

I care about the unglamorous parts: idempotent payments, role-based access,
transaction integrity, and APIs other people can actually integrate against.
