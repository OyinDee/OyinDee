I build complete products, not just endpoints. That means the database schema, the
API, the React front end, and the deployment — payments, wallets, order systems,
real-time messaging and admin dashboards, shipped end to end.

I care about the unglamorous parts: idempotent payments, role-based access,
transaction integrity, and interfaces other people can actually use.
